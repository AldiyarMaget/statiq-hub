**Ожидаемый результат:** объяснение КСП + связь через CsiInstance + источник METHODOLOGY.md

---

### Вопрос 2
```
Какие роли нужны для работы с формами в системе Метаданные — для просмотра, редактирования и согласования?
```
**Ожидаемый результат:** таблица ролей из ROLES.md:
- Просмотр → `EStatMETA_VIEW`
- Редактирование → `EStatMETA_EDIT`
- Работа с формами → `EStatMETA_FORM`
- Согласование формы → `EStatMETA_FORM` + `EStatMETA_AGREEMENT`
- Утверждение формы → `EStatMETA_FORM` + `EStatMETA_CONFIRMATION`
