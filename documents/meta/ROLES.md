## 1. Общие роли доступа к системе

### 1.1 Центральные роли (полный доступ)
🏷 **Темы:** EStat00, EStatIVC, центральный аппарат, ИВЦ, полный доступ, все регионы
роль
| Роль | Кому выдаётся | Что даёт |
|------|---------------|----------|
| `EStat00` | Центральный аппарат Комитета по статистике | Полный доступ ко всем регионам (`isAll = true`) |
| `EStatIVC` | РГП ИВЦ г. Алматы | Полный доступ ко всем регионам (`isAll = true`) |

### 1.2 Региональные роли
🏷 **Темы:** региональный доступ, EStat11, EStat75, EStat79, регион, код региона

Формат: `EStat` + двузначный код региона.
роль
| Роль | Регион |
|------|--------|
| `EStat11` | Акмолинская область |
| `EStat12` | Актюбинская область |
| `EStat13` | Алматинская область |
| `EStat14` | Атырауская область |
| `EStat75` | г. Астана |
| `EStat79` | г. Алматы |

Региональный пользователь видит **только данные своего региона**.

### 1.3 Отраслевые роли
🏷 **Темы:** отраслевой доступ, EstatSector, отрасль

Формат: `EstatSector` + двузначный код отрасли (например `EstatSector01`, `EstatSector02`).
роль
Отраслевой пользователь видит данные **только своей отрасли**.

### 1.4 Принцип прав доступа

| Тип пользователя | Роль | Что видит |
|------------------|------|-----------|
| Центральный | `EStat00`, `EStatIVC` | Все регионы, все отрасли, любые операции |
| Региональный | `EStatXX` | Только свой регион |
| Отраслевой | `EstatSectorXX` | Только своя отрасль |
| Комбинированный | региональная + отраслевая | Свой регион И своя отрасль |
роль

## 2. Роли компонента META

🏷 **Темы:** META роли, EStatMETA, редактирование META, просмотр META, согласование META, утверждение META

Все роли META выдаются пользователям: **ЦА** (Центральный аппарат), **ИВЦ**, **ИВЦ г.Алматы**.

### 2.1 Базовые роли META
роль
| Код | Роль | Разрешение |
|-----|------|------------|
| R1 | `EStatMETA_VIEW` | Просмотр компонента Метаданные |
| R2 | `EStatMETA_INPUT_DATA` | Ввод данных компонента Метаданные |
| R3 | `EStatMETA_EDIT` | **Редактирование** данных компонента Метаданные |
| R4 | `EStatMETA_AGREEMENT` | **Согласование** компонента Метаданные |
| R5 | `EStatMETA_CONFIRMATION` | **Утверждение** компонента Метаданные |
| R6 | `EStatMETA_ADMINISTRATION` | Администрирование + просмотр логов (только ИВЦ) |

### 2.2 Роли по разделам META

🏷 **Темы:** показатели КСП, формы, акронимы, разрезности, единицы измерения, алгоритмы, публикации
роль
| Код | Роль | Раздел системы |
|-----|------|----------------|
| R7 | `EStatMETA_KSP` | Показатели (КСП) |
| R8 | `EStatMETA_FORM` | Формы |
| R9 | `EStatMETA_AKRONYM` | Акронимы |
| R10 | `EStatMETA_SPACE_INSTANCE` | Экземпляры разрезности (ЭР) |
| R11 | `EStatMETA_MEASURE` | Единицы измерения |
| R12 | `EStatMETA_ALGORYTHMS` | Алгоритмы ИСО |
| R13 | `EStatMETA_ADAPTER` | Переходники |
| R14 | `EStatMETA_CHARACTERISTICS` | Ведение характеристик |
| R15 | `EStatMETA_PUBLICATION` | Публикации и тиражи |
| R21 | `EStatMETA_BUILDER_FORM` | Построитель форм |

### 2.3 Комбинированные роли META (нужны обе одновременно)
роль
🏷 **Темы:** согласование формы, утверждение формы, комбинация ролей

| Комбинация ролей | Что даёт |
|-----------------|----------|
| `EStatMETA_FORM` + `EStatMETA_AGREEMENT` | Согласование формы |
| `EStatMETA_FORM` + `EStatMETA_CONFIRMATION` | Утверждение формы |
| `EStatMETA_REGISTRY` + `EStatMETA_AGREEMENT` | Согласование регистров |
| `EStatMETA_REGISTRY` + `EStatMETA_CONFIRMATION` | Утверждение регистров |
| `EStatMETA_BUILDER_REPORT` + `EStatMETA_EDIT` | Построитель выходных таблиц (R20) |

> ⚠️ Комбинированные роли: **обе роли должны присутствовать у пользователя одновременно**.
роль
