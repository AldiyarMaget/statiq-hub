## 1. НАЧАЛО РАБОТЫ
🏷 **Темы:** НАЧАЛО РАБОТЫ

### 1.1 Как войти в систему
🏷 **Темы:** Как войти в систему, вход, логин, пароль, авторизация, браузер, e-stat

**Что вам понадобится:**
- Компьютер с браузером (Google Chrome, Firefox, Microsoft Edge)
- Интернет
- Ваши учётные данные (логин и пароль)

**Пошагово:**

1. **Откройте браузер** и введите адрес системы в адресную строку:
   ```
   http://<адрес сервера>/meta
   ```
   Попросите адрес у своего администратора, если его не знаете.

2. **Вы увидите экран входа** с полями:
    - **Логин** — введите ваше рабочее имя (например, `ivanov`)
    - **Пароль** — введите ваш пароль
    - Выберите язык (Русский 🇷🇺 или Казахский 🇰🇿)

3. **Нажмите кнопку** «Вход» или нажмите клавишу Enter

4. **Если данные верны**, вы попадёте в главное меню системы

5. **Если ошибка доступа:**
    - Проверьте правильность логина и пароля
    - Убедитесь, что вам даны права доступа
    - Свяжитесь с администратором (`ИВЦ`)

## 2. ГЛАВНОЕ МЕНЮ
🏷 **Темы:** ГЛАВНОЕ МЕНЮ

Система организована в **три больших раздела меню**. Нажмите на название раздела, чтобы раскрыть его функции.

### РАЗДЕЛ 1: МОДУЛИ (основные функции)
🏷 **Темы:** РАЗДЕЛ 1: МОДУЛИ (основные функции)

Это главный раздел, где вы работаете с показателями и формами.

#### 📊 **Ед.изм. показателя** — единицы измерения показателей
🏷 **Темы:** Ед.изм. показателя — единицы измерения показателей
**Для чего:** Добавлять и редактировать единицы измерения (тысячи тенге, человека, тонны и т.д.)

**Что можно делать:**
- Посмотреть список всех единиц
- Добавить новую единицу
- Изменить существующую
- Удалить (если не используется)

#### 📊 **Ед.изм. элементов** — единицы для отдельных элементов
🏷 **Темы:** Ед.изм. элементов — единицы для отдельных элементов
**Для чего:** Настройка более сложных единиц, привязанных к отдельным показателям

#### 🎯 **КСП (Классификационный Статистический Показатель)**
🏷 **Темы:** КСП (Классификационный Статистический Показатель)
**Для чего:** Управлять показателями, которые собирают. Например, «Объём производства», «Численность занятых» и т.д.

**Что можно делать:**
- Посмотреть все показатели в виде дерева (иерархия)
- Добавить новый показатель
- Изменить описание или единицу измерения
- Удалить неиспользуемый показатель
- Привязать к показателю разрезности

**Как узнать:** В левой части экрана видна иерархия всех показателей. Нажмите на показатель, чтобы посмотреть его свойства в центральной части.

#### 🔍 **Разрезности** — детализация данных
🏷 **Темы:** Разрезности — детализация данных
**Для чего:** Описать, по каким признакам нужна детализация (по регионам, отраслям, видам деятельности и т.д.)

**Что это значит:**
- Показатель можно собирать "в целом" (одно число)
- Или "по разрезам" (отдельно по каждому региону, отделению и т.д.)
- Разрезность — это набор "осей" для такой детализации

**Что можно делать:**
- Создать новую разрезность
- Добавить к ней измерения (оси)
- Редактировать существующую
- Удалить неиспользуемую

#### 📋 **Формы** — бланки статистической отчётности
🏷 **Темы:** Формы — бланки статистической отчётности
**Самый важный раздел для большинства работников.**

**Для чего:** Управлять формами, которые предприятия заполняют и отправляют

**Примеры форм:**
- Форма 1-П: Отчёт о производстве промышленной продукции
- Форма 11-МЕД: Отчёт по здравоохранению
- И многие другие...

**Что можно делать:**
- Посмотреть все формы в виде дерева
- Создать новую форму или версию формы
- Добавить показатели в форму
- Настроить разрезность (как будут даны данные)
- Установить сроки сдачи (календарь)
- Отправить форму на согласование
- Утвердить форму

**Как работать с формами подробно** — см. в разделе 3.1 этой инструкции.

#### 🔗 **Переходники** — маппинг между классификаторами
🏷 **Темы:** Переходники — маппинг между классификаторами
**Для чего:** Если нужно преобразовать коды из одной системы в другую

**Пример:** Коды ОКЭД (вид деятельности) переводить в коды ОКЭДП (более детальная классификация)

#### 📝 **Акронимы** — сокращённые названия осей разрезности

![Меню Модули с выбранным пунктом Акронимы](/meta/images/img_4.png)

🏷 **Темы:** Акронимы — сокращённые названия осей разрезности
**Для чего:** Задать имена и коды для измерений в разрезностях

**Примеры акронимов:**
- `REG` — регион (код региона)
- `OKVED` — вид деятельности по ОКЭД
- `COMP_SIZE` — размер компании

#### ✅ **Отчёты по качеству** — документы о качестве данных
🏷 **Темы:** Отчёты по качеству — документы о качестве данных
**Для чего:** Описать методологию и качество конкретного показателя

#### 📌 **Мониторинг задач** — отслеживание выполнения
🏷 **Темы:** Мониторинг задач — отслеживание выполнения
**Для чего:** Смотреть, какие задачи выполняются в системе, какие завершены

#### 📔 **Логирование** — журнал всех изменений
🏷 **Темы:** Логирование — журнал всех изменений
**Для чего:** Посмотреть, кто и когда что изменил в системе

**Что можно увидеть:**
- Кто (какой пользователь) сделал изменение
- Что изменилось (название показателя, форма и т.д.)
- Когда это произошло (дата и время)
- Модуль, в котором произошло изменение (КСП, Формы и т.д.)

**Фильтры:** Можно отфильтровать по дате, пользователю, типу изменения (добавление/удаление/редактирование)

#### 📅 **Периоды отчётности** — с какой периодичностью отчитываться
🏷 **Темы:** Периоды отчётности — с какой периодичностью отчитываться
**Для чего:** Установить, как часто отправляются данные

**Примеры:**
- Месячная отчётность
- Квартальная
- Полугодовая
- Годовая

#### 📋 **Ведение атрибутов** — дополнительные свойства объектов
🏷 **Темы:** Ведение атрибутов — дополнительные свойства объектов
**Для чего:** Добавлять расширенные свойства к формам, показателям и т.д.

**Примеры атрибутов:**
- Пароль для доступа к форме

#### 📰 **Публикации** — издания со статистикой
🏷 **Темы:** Публикации — издания со статистикой
**Для чего:** Управлять статистическими публикациями, выпусками, файлами

**Что это:**
- Каждую публикацию можно описать (название, ответственный)
- Разбить на выпуски (номера)
- Прикрепить файлы (PDF, Excel и т.д.)

#### 📊 **Публикуемость данных** — какие данные в открытом доступе
🏷 **Темы:** Публикуемость данных — какие данные в открытом доступе

### 3.1 КАК СОЗДАТЬ НОВУЮ ФОРМУ (БЛАНК ОТЧЁТНОСТИ)
🏷 **Темы:** КАК СОЗДАТЬ НОВУЮ ФОРМУ (БЛАНК ОТЧЁТНОСТИ), создать форму, новая форма, бланк, индекс формы, версия, календарь, согласование

**Кто делает:** Методолог, аналитик отдела форм

**Что нужно подготовить:**
- Код формы (например, 1-П, 11-МЕД)
- Название на русском и казахском
- Периодичность сдачи (ежемесячно, ежеквартально и т.д.)
- Список показателей, которые собираются в этой форме
- Разрезности (как будут даны данные)

**Пошагово:**

1. **Откройте раздел «Формы»** в левом меню

   ![Главный экран модуля Формы: дерево форм по годам и версии формы](/meta/images/img.png)

    - Нажмите на слово "Формы" в меню МОДУЛИ

2. **Создайте новый индекс формы (если его ещё нет)**
    - Если это совершенно новый бланк, сначала создайте индекс (уникальный код бланка)
    - Нажмите кнопку **«Добавить»** в верхней части экрана
    - Введите код (например, `1-П`)
    - Введите название на русском и казахском
    - Нажмите **«Сохранить»**

3. **Создайте версию формы**
    - После создания индекса нажмите **«Новая версия»**
    - Выберите периодичность (месячная, квартальная и т.д.)
    - Укажите дату начала действия формы
    - Нажмите **«Сохранить»**

4. **Добавьте показатели в форму**
    - Найдите вкладку **«Показатели»** или **«КСП в форме»**
    - Нажмите **«Добавить показатель»**
    - Выберите нужный показатель из списка
    - Выберите единицу измерения
    - Выберите разрезность (по какой детализации будут данные)
    - Нажмите **«Добавить»**
    - Повторите для других показателей

5. **Настройте структуру формы (разделы)**
    - Перейдите на вкладку **«Разделы»**
    - Создайте разделы (например, раздел 1 - производство, раздел 2 - продажи)
    - Для каждого раздела привяжите показатели

6. **Установите сроки сдачи (календарь)**
    - Перейдите на вкладку **«Календарь»**
    - Нажмите **«Авто-генерация»** — система автоматически создаст дни для сдачи
    - Система предложит даты начала, дни ответа, дни регионального уровня, дни финального уровня
    - Вы можете отредактировать даты вручную
    - После редактирования нажмите **«Отправить на согласование»**

7. **Отправка на согласование**
    - После нажатия кнопки система отправит форму согласующим и утверждающим
    - Каждый согласующий должен нажать **«Согласовать»**
    - После согласования всех, утверждающий нажимает **«Утвердить»**
    - Только после утверждения форма готова к использованию

8. **Готово!**
    - Форма создана, показатели добавлены, сроки установлены
    - Система готова получать данные по этой форме

### 3.2 КАК ДОБАВИТЬ НОВЫЙ ПОКАЗАТЕЛЬ (КСП)
🏷 **Темы:** КАК ДОБАВИТЬ НОВЫЙ ПОКАЗАТЕЛЬ (КСП), создать показатель, добавить КСП, новый показатель, единица измерения

**Кто делает:** Методолог, специалист по показателям

**Пошагово:**

1. **Откройте раздел «КСП»** в левом меню

   ![Модуль Показатели (КСП): список показателей и разрезность показателя](/meta/images/img_1.png)

    - Нажмите на слово "КСП" в меню МОДУЛИ

2. **Нажмите кнопку «Добавить новый показатель»** в верхней части экрана

3. **Заполните форму:**
    - **Код** — уникальный код показателя (например, 12345)
    - **Наименование (РУ)** — название на русском (например, «Объём производства»)
    - **Наименование (КЗ)** — название на казахском
    - **Единица измерения** — выберите из выпадающего списка (тысячи тенге, человека и т.д.)
    - **Дата начала действия** — с какой даты показатель действует
    - **Дата окончания действия** — если показатель временный (можно оставить пусто)
    - **Родительский показатель** — если это подпоказатель, выберите родителя (или оставьте пусто)

4. **Нажмите кнопку «Сохранить»**
    - Показатель создан

5. **(Дополнительно) Привяжите разрезности**
    - Перейдите на вкладку **«Разрезности»**
    - Нажмите **«Добавить разрезность»**
    - Выберите разрезность (по регионам, отраслям и т.д.)
    - Нажмите **«Сохранить»**

### 3.3 КАК СОЗДАТЬ НОВУЮ РАЗРЕЗНОСТЬ
🏷 **Темы:** КАК СОЗДАТЬ НОВУЮ РАЗРЕЗНОСТЬ, создать разрезность, добавить измерение, ось, акроним

**Кто делает:** Методолог, специалист по метаданным

**Разрезность** — это набор "осей" детализации. Например:
- Разрезность "по регионам и отраслям" включает две оси: регион и отрасль
- Разрезность "по видам деятельности" включает одну ось: вид деятельности

**Пошагово:**

1. **Откройте раздел «Разрезности»** в левом меню

   ![Меню Модули с выбранным пунктом Разрезности](/meta/images/img_3.png)

### ❓ Как работает согласование календаря?
🏷 **Темы:** Как работает согласование календаря?

**Ответ:** Процесс согласования:

```
1. Вы создали проект календаря (даты сдачи) → 
2. Нажали "Отправить на согласование" → 
3. Система нашла согласующих и утверждающих → 
4. Каждый согласующий нажимает "Согласовать" → 
5. Когда все согласовали, утверждающий нажимает "Утвердить" → 
6. Календарь становится активным, даты вступают в силу →

```

Важно: **Пока документ не в статусе APPROVED, вы не можете создать новый проект.** Система выведет ошибку: "Найден не утверждённый документ".

### ❓ Что такое «дата действия» (dbeg / dend)?
🏷 **Темы:** Что такое «дата действия» (dbeg / dend)?

**Ответ:**
- **dbeg (date begin)** — дата начала действия (с какой даты объект используется)
- **dend (date end)** — дата окончания действия (до какой даты объект используется)

Пример:
- Форма 1-П **dbeg** = 01.01.2023, **dend** = 31.12.2023
- Это значит, форма действует только в 2023 году
- В 2024 году создаётся новая версия формы с новыми датами

Обратитесь в отдел ИВЦ (администратор системы), если:

✅ **Технические проблемы:**
- Не получается войти в систему
- Система работает медленно или падает
- Браузер выводит ошибки
- Файлы не загружаются

- Вам не видны функции, которые вам нужны

- Вас нужно добавить в список согласующих

- Вы не можете найти нужный показатель или форму
- Кажется, потеряны данные
- Нужна срочная выгрузка/загрузка данных

✅ **Интеграции:**
- Данные не передаются в ТАЛДАУ
- Статус сообщения "ошибка" — нужна помощь
- Нужна настройка новой интеграции

5.  Какие контроли и предупреждения есть при заполнении базового календаря?

Ответ:

В текущей реализации МЕТА логика настроена следующим образом:
• дата начала сдачи должна быть меньше срока сдачи респондентом;
• срок сдачи респондентом должен быть меньше или равен сроку сдачи регионом;
• срок сдачи регионом должен быть меньше срока сдачи республикой.
Система формирует предупреждение: «Выбранная дата приходится на выходной день. Продолжить?»; В зависимости от настройки:
a. либо блокирует сохранение даты;
b. либо позволяет продолжить после подтверждения пользователем;

## ШПАРГАЛКА — БЫСТРЫЕ ССЫЛКИ

**Самые частые действия:**

1. **Создать новую форму** → МОДУЛИ → Формы → Добавить → заполнить поля → добавить показатели → установить календарь → отправить на согласование

2. **Добавить новый показатель** → МОДУЛИ → КСП → Добавить → заполнить данные → сохранить

3. **Посмотреть, кто что изменил** → МОДУЛИ → Логирование → применить фильтры

4. **Согласовать документ** → открыть раздел (Формы или Ведение атрибутов) → найти документ → нажать "Согласовать" или "Утвердить"

5. **Отправить на ТАЛДАУ** → ИНТЕГРАЦИЯ → Талдау → выбрать показатель → нажать "Отправить"
